# Python Voice Assistant 🎙️

## Project Description
Python Voice Assistant is a simple voice-controlled assistant developed using Python. It listens to user voice commands, understands them, and performs basic tasks through voice interaction.

The project demonstrates how Python can be used to build a basic personal assistant using speech recognition and text-to-speech technologies.

## Objectives
- To understand speech recognition in Python.
- To convert text responses into speech.
- To automate basic tasks using voice commands.
- To practice Python functions, loops, and conditional statements.

## Features
- Greets the user.
- Recognizes voice commands.
- Tells the current time.
- Tells the current date.
- Opens Google.
- Opens YouTube.
- Searches Google using voice commands.
- Responds through voice.
- Exits when the user says "Bye" or "Stop".

## Technologies Used
- Python 3
- SpeechRecognition
- pyttsx3
- PyAudio
- datetime
- webbrowser

## Installation

First, install the required Python libraries:

```bash
python -m pip install SpeechRecognition
python -m pip install pyttsx3
python -m pip install PyAudio
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the required libraries.
4. Connect a working microphone.
5. Run the following command:

```bash
python assistant.py
```

6. Speak your commands when the assistant starts listening.

## Available Voice Commands

| Voice Command | Action |
|---|---|
| Hello | Greets the user |
| What is the time? | Tells current time |
| What is the date? | Tells current date |
| Open Google | Opens Google |
| Open YouTube | Opens YouTube |
| Search for Python | Searches Google |
| Bye | Closes the assistant |

## Requirements
